# MDG Pro - 前端平台 README

## 1. 系統定位：使用者互動與數據可視化介面

本系統是使用者與 MDG Pro 平台互動的主要介面，採用 **Flask** 搭配 **JavaScript** 的前後端分離架構。所有您在畫面上看到的數據，都是動態從後端 API 獲取的。

在介面設計上，我們**參考了多家新創公司的成功案例**，力求打造一個現代、直觀且使用者體驗流暢的產品。

---

## 2. 核心功能與進度

前端的核心使用者流程，**幾乎都已完成與後端的完整串接**：

- **✅ 完整的核心流程**: 使用者可以順暢地體驗從**登入**、進入**個人儀表板**、查看**我的群組**、深入到**群組總覽**、再到點擊**單一成員的儀表板**或**行程詳細報告**的完整流程。
- **✅ 嚴格的權限控制**: 已成功實現管理員與一般成員的介面分離。同樣一個「群組總覽」頁面，**管理員**登入會看到所有管理按鈕和數據圖表；而**一般成員**登入時，這些功能都會被自動隱藏，確保了系統的安全性與角色的清晰劃分。
- **✅ 豐富的數據可視化**:
    - **動態圖表**: 無論是個人儀表板還是群組的趨勢分析，所有圖表都已串接後端 API，可顯示真實數據，並支援日期範圍篩選。
    - **PDF 報表預覽**: 「列印報表」功能已能正確呼叫後端 API，並在新分頁中開啟由後端即時生成的 PDF 預覽。
- **✅ AI 功能整合**: AI 客服聊天室已成功串接後端，使用者可以直接與 AI 進行互動。

**結論：前端平台的整體架構和主要功能都已完成，為使用者提供了功能完整、權限清晰、體驗流暢的互動介面。**
