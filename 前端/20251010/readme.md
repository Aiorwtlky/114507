# MDG Pro - 前端平台 (Frontend Platform)

## 1. 總覽

本系統是使用者（駕駛員、車隊管理者）與 MDG Pro 平台互動的主要介面。採用 **Flask** 作為網頁伺服器，**原生 JavaScript** 作為前端動態功能的驅動核心。其架構為標準的**前後端分離**模式，所有頁面內容皆透過 `fetch` API 向後端請求 JSON 資料，並在瀏覽器端進行動態渲染。

在介面設計上，我們參考了多家國內外成功新創公司的案例，力求打造現代、直觀且使用者體驗流暢的產品。

✅ 核心頁面串接: 核心使用者流程幾乎都已完成串接。從登入、儀表板、到具備完整權限控制的群組管理頁面，所有功能都已實現。

角色分離: 已成功實現管理員與一般成員的介面分離。例如，在「群組總覽」頁面，只有管理員能看到「新增成員」、「趨勢分析」等管理功能。
