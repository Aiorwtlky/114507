🎯 智慧評分邏輯

採用時間區間化 + 分類評分機制，精確反映駕駛行為

1

時間切分

將整趟行程切分為多個 15 分鐘區間

例如：09:00-11:30 的行程 → 區間1: 09:00-09:15 → 區間2: 09:15-09:30 → 區間3: 09:30-09:45 ... 共 10 個區間
2

事件分類

根據 event_number 前綴分類

A 開頭 → 車內事件 (如 A001: 未繫安全帶) B 開頭 → 車外事件 (如 B003: 未保持安全距離)
3

區間獨立計分

每個區間從 100 分開始，根據該區間內的違規扣分

區間1: 100 - 5(事件A) - 3(事件B) = 92 分 區間2: 100 - 8(事件A) = 92 分 區間3: 100 分 (無違規)
4

最終分數計算

關鍵規則：

IF 某類別所有區間 >= 60 分: 該類別最終分數 = 所有區間的平均值 ELSE (有任何區間 < 60 分): 該類別最終分數 = 所有區間中的最低分 總分 = (車內分數 + 車外分數) / 2

實際案例

行程共 4 個區間： 車內區間分數: [88, 92, 75, 82] → 所有 >= 60 → in_car_score = (88+92+75+82)/4 = 84.25 車外區間分數: [95, 55, 88, 90] → 區間2 < 60 ⚠️ → out_car_score = min([95, 55, 88, 90]) = 55 總分 = (84.25 + 55) / 2 = 69.625

權限管理架構

JWT Token 機制

  • 登入後獲取 access_token
  • 每次 API 請求帶上 Token
  • 後端自動解析出 user
  • 15 分鐘後過期需 refresh

三層權限體系

  • 一般成員：看自己資料
  • 群組管理員：管理成員
  • 系統管理員：全站權限

自訂 Permission 類別

  • IsOwnerOrAdmin
  • IsGroupOwnerOrAdmin
  • IsAnnouncementPublisher
