# MDG Pro - 車機端系統 README

## 1. 系統定位：前線的數據採集與 AI 分析中心

本系統是在車輛硬體上運行的應用程式，是我們所有數據的**源頭**。它採用 Python 搭配 `OpenCV` 與 `YOLOv8` 模型，負責即時的影像分析。

**系統運作流程：**
1.  **接收影像**：從攝影機獲取即時影像串流。
2.  **AI 分析**：透過多個 AI 偵測器，即時分析駕駛員的行為與車外環境。
3.  **離線儲存**：將偵測到的違規事件，安全地存入本機的 SQLite 資料庫，確保在沒有網路的環境下，資料也不會遺失。
4.  **雲端同步**：一旦網路恢復，資料同步服務就會自動將所有數據上傳至後端伺服器。

---

## 2. 核心功能與進度

車機端的 AI 偵測與資料上傳功能已開發完成：

- **✅ 多維度 AI 事件偵測**: 已實現多個核心偵測器：
    - **疲勞偵測器**: 負責偵測駕駛員的疲勞狀態（如閉眼、打哈欠）。
    - **分心偵測器**: 負責偵測分心行為（如使用手機、臉部離開）。
    - **車外環境偵測器**: 負責偵測車外事件（如未保持安全車距）。
- **✅ 離線資料保障**: 所有行程與事件資料都會先寫入本機資料庫，確保數據的完整性與可靠性。
- **✅ 智慧化雲端同步**: 已開發完成 API 客戶端，負責將本機資料在適當時機（如網路恢復時）自動上傳至後端，完成數據閉環。

**結論：車機端已具備完整的 AI 偵測、離線儲存與雲端同步能力，是整個系統可靠的數據基礎。**
