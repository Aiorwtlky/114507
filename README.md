MDG Essentials - 記錄器端設備 (Onboard Device System)
1. 總覽
本系統是安裝於車輛硬體上的邊緣運算應用程式。其核心職責是即時影像分析、危險事件偵測、本機資料儲存與雲端同步。

程式採用 Python 編寫，利用 OpenCV 進行影像處理，並載入 YOLOv8 模型進行物件偵測與行為分析。
